# REPO ORBIT

**Watch your code evolve.**

REPO ORBIT is an offline Git-history visualization tool. The v0.8.0 development candidate has completed Linux benchmarking on Requests, Flask and uv; native Windows and macOS validation remains pending.

## Repository bootstrap status

This repository was initialized for a controlled, reviewable import. Product source, native benchmark runners and CircleCI configuration are staged on a development branch and must not be treated as a published, accepted release.

- Runtime: local Python and Git, not GitHub Pages or GitHub Actions.
- Validation: CircleCI for build/test/evidence only; no application hosting.
- CI: manually triggered pipelines; Windows/macOS remain HOLD until native evidence is accepted.
- Licensing: pending an explicit final decision. Public visibility is **not** an open-source license.

See the active development PR for the CircleCI setup and validation plan.
